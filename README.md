# Rill EPUB 阅读器 · 0.2.3

支持 EPUB 2/3、中文正文、目录与书内链接、字号调整、阅读主题、阅读位置保存及恢复。书库关联 Rill 多维表或视图，所有数据交互遵循统一 Host API 2。

## 安装

在 Rill 插件管理中添加 GitHub 仓库 `jzbjing-pixel/render`，安装签名包 `dist/rill-plugin.git.zip`。发布者公钥见 `publisher.json`，沿用既有发布者身份。

## 0.2.2 更新

EPUB 文件上限由 8 MiB 调整为 64 MiB；展开后总量最多 256 MiB、4096 个条目，单条目最多 32 MiB。保留解压大小、路径和正文安全检查。需要宿主的统一文件读取接口同步支持 64 MiB；旧宿主仍可能报告 8 MiB 限额。

已验证 10.1、13.8、51.2 MiB EPUB 的目录解析与首章显示，签名校验、EPUB 2/3、正文安全过滤、阅读进度及桌面/手机布局通过。

不支持 DRM。固定版式、原书 CSS/字体的完整还原、注释、划线与全文搜索尚未实现。

## 0.2.3 更新

阅读器可引用宿主共享记录视图与标签模块，视图配置使用统一 API 更新，需要支持对应能力的新版宿主。上述大 EPUB 支持继续保留。

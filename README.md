# EPUB 阅读器

当前签名版 **0.2.7**，需要 **Rill 0.1.8 / Host API 3**。旧宿主会拒绝安装，请先更新宿主。

本轮修复独立数据授权、映射冲突检查、更新前保存、会话撤销和共享 SDK。首次升级后需重新确认连接；原表结构和数据保留，不进行隐式迁移。

## 下载与历史

宿主 GitHub 安装入口继续读取 dist/rill-plugin.git.zip。归档 [0.2.7](releases/0.2.7/rill-plugin.git.zip)；上一版 [0.2.6](releases/0.2.6/rill-plugin.git.zip)。既有历史包和提交保持原样。签名及哈希见 [release.json](releases/0.2.7/release.json)。

仓库只发布签名运行包及公开说明，不包含私钥、个人数据或私有开发源码。

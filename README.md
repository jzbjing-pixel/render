# EPUB 阅读器

当前签名版本：**0.2.6**。统一连接、字段映射、宿主导航；封面读取缩略图缓存，后台保留阅读位置。

## 安装

在 Rill 插件管理中添加 GitHub 仓库 `jzbjing-pixel/render`，使用本仓库 `publisher.json` 的原发布者公钥和 `rill-plugin.git.zip` 下载入口，检查更新后选择安装。`dist/rill-plugin.git.zip` 始终指向本仓库最新正式签名包。

本次版本需要包含 2026-10-13 统一连接、字段补齐、列表/标签/筛选模块、主题与缩略图缓存实现的新版 Rill 宿主。只更新插件不会更新宿主；旧宿主请保留原插件版本并先更新宿主。Host API 协议仍为 2，协议号本身不代表具备本次新增能力。

## 版本保留

本次新包保存在 [0.2.6](releases/0.2.6/rill-plugin.git.zip)，此前签名包保存在 [0.2.4](releases/0.2.4/rill-plugin.git.zip)。Git 历史继续保留，不重写旧版本。校验信息见 [release.json](releases/0.2.6/release.json)。

## 数据与安全

沿用原发布者密钥。插件通过公共 Host API 访问授权数据；新表依据契约创建字段，旧表仅补缺失字段，现有值与原附件保留。字段类型冲突会拒绝保存。列表缩略图由宿主生成缓存，插件读取缩略图字段。

此仓库用于签名运行包发布。开发源码保存在本地开发项目；发布包不包含私钥、个人数据或本地宿主内部实现。
